# data-poi

Data repository for the **POI — global travel registry** demonstration dictionary of the
[OpenCDD](https://github.com/opencdd) project.

- `reference-docs/examples/poi.cddal` — the dictionary itself
  (single source; CDDAL plain text).
- `data/poi/database.json` — browser JSON, generated by
  `rake browser:build` (unit references bound into the
  [IEC 62720](https://opencdd.github.io/d/iec-62720/) units dictionary,
  which is free in its entirety per the IEC CDD License Agreement §6).
- `units.json` — compact IEC 62720 unit index used for the binding
  (same §6 terms).

The verified global spot registry: DBpedia candidates, per-entry
Wikipedia verification, Wikidata (CC0) enrichment. Sources and
attribution are carried in the fixture header (Wikipedia/DBpedia
CC BY-SA; Wikidata CC0). `rake browser:harvest_poi` re-runs the
pipeline; the quarterly workflow refreshes it via PR.

The engine is [opencdd-ruby](https://github.com/opencdd/opencdd-ruby)
— an implementation of working with OpenCDD data, used read-only here.
